# Cisco Packet Tracer Networking Labs

Hands-on networking projects created using Cisco Packet Tracer to develop practical skills in networking, IT support, and troubleshooting.

## Projects

### 01 - Basic LAN Configuration

A simple LAN consisting of two PCs connected through a Cisco 2960 switch.

**Skills demonstrated:**

* IPv4 addressing
* Subnetting fundamentals
* LAN configuration
* Layer 2 switching
* ICMP connectivity testing
* Basic troubleshooting

[View Project](./01-basic-lan)

## Tools

* Cisco Packet Tracer

## Purpose

These are personal hands-on learning projects designed to build practical networking skills and demonstrate technical knowledge through documented labs.
